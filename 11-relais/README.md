# 11-relais

Étude de cas bonus « Relais » : deux exercices, joués par chacun sur son poste. Suivez la fiche envoyée par le formateur ; sa section 0 prépare le poste.

| Dossier | Contenu |
|---|---|
| `tickets-client/` | la transcription d’une réunion avec la cliente, le gabarit de ticket, un brouillon de ticket et l’agent `portier` de Claude Code |
| `application/` | Relais, application Symfony de démonstration (données fictives), ses tests Playwright, le test de ses règles (PHPUnit) et les agents de Playwright |
| `outils/` | les fichiers que la fiche fait copier ou appliquer, et `verifier-poste.js` ; ce dossier ne s’ouvre pas dans Claude Code |

`tickets-client/` et `application/` s’ouvrent séparément, chacun dans sa propre session de Claude Code. Personnes, entreprise et données sont fictives.
