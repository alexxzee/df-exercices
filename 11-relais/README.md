# 11-relais

Étude de cas bonus « Relais ». **Démonstration conduite par le formateur : rien à lancer.** Suivez la fiche qu’il vous envoie.

| Dossier | Contenu |
|---|---|
| `tickets-client/` | la transcription d’une réunion avec la cliente, le gabarit de ticket et deux agents de Claude Code : `decoupeur` et `portier` |
| `application/` | Relais, application Symfony de démonstration (données fictives), et ses tests Playwright |

Les deux dossiers s’ouvrent séparément, chacun dans sa propre session de Claude Code. Personnes, entreprise et données sont fictives.
